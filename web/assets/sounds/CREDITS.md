# Sound credits

Small mono WAV files, trimmed, level-normalised and (Kenney) resampled to
24 kHz by Claude from the sources below. The generated sounds in
`web/js/audio.js` play instead if a file doesn't load.

| Files | Source | Licence |
|---|---|---|
| `shot_near_0-3.wav`, `shot_far_0-2.wav` | ShotSpotter, Inc., "Sample Live Fire Test Data" (City of Pittsburgh live-fire test, 18 Dec 2018): single 9mm / .40 / .45 handgun shots recorded by street sensors 160-660 m away. https://github.com/ShotSpotter/research.accuracy-of-gunshot-location | CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Changes: cut to one shot, trimmed, faded, normalised. |
| `steel_0-4.wav` | Kenney, Impact Sounds 1.0 (impactMetal medium/light) | CC0 1.0 |
| `step_concrete_0-4.wav` | Kenney, Impact Sounds 1.0 (footstep_concrete) | CC0 1.0 |
| `glass_0-2.wav` | Kenney, Impact Sounds 1.0 (impactGlass_heavy) | CC0 1.0 |

Kenney: https://kenney.nl/assets/impact-sounds (taken from the CC0 copy in
https://github.com/smartpage/strongerfx-mcp history).
