Laser setup, once per room

  1. Project this page and press F for fullscreen.
  2. Plug in the USB camera (with the IR-pass filter) aimed at the screen.
  3. Setup → Start camera, allow access, pick the camera, tune the threshold.
  4. Calibrate: shoot the 4 crosshairs, then the centre to check accuracy.

Use Chrome or Edge for the best camera timing. Scores and settings stay in this browser only.
